WINDOWS PYTHON & CONDA CHEATSHEET
=================================

Problem: "pip is not recognized"
--------------------------------
Cause: pip.exe is inside your conda environment folder, not on your system PATH.

Solution 1 (use python to call pip):
  C:\Users\Chris\.conda\envs\af3_thesis\python.exe -m pip install PACKAGE_NAME

Solution 2 (use full pip path):
  C:\Users\Chris\.conda\envs\af3_thesis\Scripts\pip.exe install PACKAGE_NAME

Solution 3 (activate conda environment first):
  C:\Users\Chris\.conda\Scripts\conda.exe activate af3_thesis
  pip install PACKAGE_NAME
  (Note: conda.exe itself might also not be on PATH - use Solution 1 or 2 instead)


Problem: Running tests fails with "ModuleNotFoundError: No module named 'pytest'"
----------------------------------------------------------------------------------
Cause: You're running python from a different environment (or system python) that
       doesn't have pytest installed.

Solution:
  C:\Users\Chris\.conda\envs\af3_thesis\python.exe -m pytest tests/test_integration.py -v

       in your system PATH.

Path Addition (Permanent Fix)
=============================
To add conda to your PATH permanently:

1. Press Win+X → System
2. Click "Advanced system settings"
3. Click "Environment Variables"
4. Under "User variables", find "Path" and click "Edit"
5. Click "New" and add:
   C:\Users\Chris\.conda\Scripts
   C:\Users\Chris\.conda\envs\af3_thesis\
   C:\Users\Chris\.conda\envs\af3_thesis\Scripts
6. Click "OK" on all dialogs
7. Open a NEW terminal window for changes to take effect

Then you can simply use:
  conda activate af3_thesis
  pip install PACKAGE_NAME
  pytest tests/ -v
